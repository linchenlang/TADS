FEATURES

为每一次查询而生

从车次到车站，从实时位置到检票口信息，TADS 覆盖列车数据查询的每一个细节。

实时正晚点

调用实时接口获取列车正晚点状态，标注预计正点、预计晚点，实时掌握列车动态。

车站大屏

实时获取出发 / 到达大屏数据，展示车次、图定时间、大屏状态、检票口与出站口信息。

车次完整详情

车次类型、复车次、路局、车型、配属、担当、运行时长，以及全部经停站信息。

车次实时位置

基于实际时刻表与实时正晚点数据，精确定位列车当前位置，线路图与时刻表同步聚焦。

两站间查询

输入起点与终点，一次检索获取两地间所有车次、发车到达时间、历时与运行状态。

站点时刻表

按时间排序显示经过该站的所有车次，自动计算上一班与下一班，含昨日 / 次日标记。

车厢图与动车组

查看列车车厢分布图，双击放大细节；查询动车组运行信息与车组配属详情。

物理密钥认证

基于 PN532 读卡器的 NFC 认证体系，管理员 M1 卡与 ROOT NTAG215 卡双重校验。

离线模式

本地查询引擎贯穿每一次查询，断网状态下核心功能仍可正常使用，无需等待。

PLATFORMS

三端覆盖，处处一致

服务器端负责数据集中管理与 API 服务，桌面客户端提供完整的查询与编辑能力，Web 端打开浏览器即可使用。

SERVER

服务器端

数据集中管理与对外 API 服务的核心，负责列车数据的存储、更新、合并组计算与权限校验。

  • 列车数据增删改查与持久化
  • 内置 Flask API 服务与 V1/V2 接口代理
  • 还原点系统与操作日志
  • 物理密钥与权限体系管理
CLIENT

桌面客户端

提供完整的数据查询、编辑与提权能力，与服务器端功能完全对齐，适合需要深入使用系统的用户。

  • 九种查询模式覆盖全部场景
  • 数据源独立切换（本地 / API）
  • 编辑、还原点、日志完整支持
  • 与服务器端安全机制完全一致
WEB

TADS-Web

轻量版本，打开浏览器即可使用，无需安装任何软件，随时随地查询列车信息。

  • 车次查询：经停站、正晚点、检票口
  • 车站查询：上一班与下一班
  • 站到站查询：两地间所有车次
  • 车站大屏：出发与到达实时同步

TECHNOLOGY

为兼容性而设计

从最新 CPU 到二十年前的老机器，TADS 都能稳定运行。

01

指令集自动适配

启动时自动检测 CPU 支持的指令集，从 AVX-512 到 SSE2、MMX，逐级回退，确保任何机器都能跑起来。

02

物理密钥 + Ed25519 签名

ROOT 身份需通过 NTAG215 卡与 Hash256 双重验证，安全等级远超传统密码方案。

03

数据持久化与原子写入

JSON 格式存储，采用临时文件 + 原子替换 + 文件锁机制，断电或崩溃也不会损坏数据。

04

还原点与操作日志

最多三个还原点，随时回滚；全部操作留痕，支持导出 CSV / JSON / TXT 三种格式。
